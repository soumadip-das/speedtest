# Continuous Bandwidth Test

A simple browser-based internet bandwidth testing tool that continuously measures **download and upload speed** while displaying the total amount of data transferred.

## Features

- 📥 Separate download speed display
- 📤 Separate upload speed display
- 📊 Total download and upload data
- ⏱️ Running time counter
- ▶️ Start and Stop controls
- 💾 Test data is discarded instead of being saved as files
- 🌐 Runs directly in a web browser

## How to Run

1. Download or clone this project.
2. Open `continuous_test.html` in Chrome, Edge, or another modern browser.
3. Click **Start**.
4. The test will continuously transfer test data and display the results.
5. Click **Stop** to end the test.

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API

## Note

This project transfers real internet data. Continuous testing can consume a significant amount of your ISP's monthly data allowance or FUP.
